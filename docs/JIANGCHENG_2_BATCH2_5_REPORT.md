## 2. Batch 2：过早巷 + 成长/进化 + 任务

### 区域与事件
- 五区：江风渡口 → 过早巷 → 桥影工坊 → 樱语山坡 → 雷鸣创想站；完成前一区解锁下一区。
- 每区 5 节点（2 事件 + 普通战 + 精英 + Boss）；**20 个事件**，第二事件节点按 seed 从额外事件池轮换。
- 事件现在会留下 **flags**（灯、桥、花、电等），后续事件可出现「需要前置线索」的强化选项；另有 `startShield` / `bossHpDelta` 影响下一场战斗。
- 共 5 个 Boss：
  - 风雨电台（暴雨/积水成渊，二阶段）；
  - **早味大厨**（热度机制：每次命中叠热度，3 层进二阶段，锅气爆炒附加脆弱）；
  - **桥影守卫**（周期性桥面封锁：下一回合支援/连携不可用）；
  - **樱信档案员**（抄录上一招：重复同一技能会被反制蓄势）；
  - **造物夜主脑**（三阶段：2/3、1/3 血量阈值，终盘全域过载）。

### 成长、进化与羁绊
- 等级 1–5，经验门槛 30/70/120/180；升级 +4 HP/+1 ATK/DEF/SPD；重复刷同节点收益最低 40%。
- **10 组进化 × 2 分支 = 20 种进化**：伞骨、早味、樱语、渡水、档案、灯火、容器、包袋、桥影、雨声。
- 3 级解锁；消耗 1 信物；预览属性/技能/配色，可回退（再消耗 1 信物）。
- 羁绊 4 档（0/3/8/15 点）；6 条连携，高级连携要求羁绊 ≥1/2。
- 进化装备顺序修复：进化后第一个装备位仍保证是伤害技，避免“进化完只会放盾”的死局。

### 任务、图鉴与分享
- **25 个任务**：故事、成长、收藏、挑战；前置可软锁，领取幂等，经验奖励可直接升级队伍。
- 图鉴三层（发现/研究/掌握）、倾向筛选、只看进化、锁定保护；容量满时优先淘汰未锁定卡，全锁则拒绝新卡。
- 挑战码 `JCM2-...` 只含队伍摘要/区域/seed，不含照片、位置、密钥。
- **v1 卡“觉醒”**：图鉴底部旧 P1 卡可生成 2.0 造物，旧图鉴只读保留并记录 `awakenedId`。
- 存档：`regionRuns` 多区进度、旧 Batch 1 存档自动迁移；导出/导入/损坏回退通过测试。

## 3. AI：六条真实链路

- `analyze`：P1 卡面设定（保留）。
- `battle-plan`：P1 敌方选招（保留）。
- **`analyze-object`**：物品语义标签（只给白名单标签）。
- **`battle-director`**：2.0 敌方导演；白名单扩到 9 种动作（含锅气爆炒/封锁/抄录/过载）。
- **`quest-director`**（本轮新增）：只从合法任务列表选一个，给短理由与提示。
- **`evolution-guide`**（本轮新增）：只从合法进化分支选一条，说明补足队伍什么、风险是什么。

客户端与服务端都做合法性校验；非法输出/超时自动回落规则，并在界面标注来源。`npm run check:ai` 六条链路实跑通过。

## 5. UI：卡片与指引

### 卡片
- **毛玻璃**：标本卡使用半透明纸面 + `backdrop-filter` 磨砂 + 内高光；`@supports` 回退到不透明纸面。
- **3D 倾斜**：鼠标移动时按指针位置轻微 rotateX/rotateY；触屏关闭；`prefers-reduced-motion` 关闭。
- **流光**：hover 时高光扫过卡片；进化卡带红/蓝双色 holographic 扫光。
- **切换动效**：主战切换 slot-pop、成员高亮、筛选淡入、技能/支援错峰入场；全部只改 transform/opacity 或受 reduced-motion 保护。

### 指引
- 顶部常驻「下一步」条：根据进度告诉玩家该捕获/组队/继续区域/领任务/进化；可跳转，也可打开完整指引。
- 「指引」抽屉：捕获、队伍、地图、战斗、成长与进化、任务与图鉴六章，步骤 + “容易踩的坑”。
- 战斗首回合 coach line：先读意图、护盾/防御减半、没资源用普攻。
- 事件被 flag 锁住时显示“还缺少前置线索”，不是无声失败。
- 任务页与进化面板都提供 AI 推荐按钮，并显示推荐理由。
- 关键数值加 `title` 提示（共鸣、羁绊等）。

## 10. 设计工程复核（emil-design-eng 口径）

| Before | After | Why |
| --- | --- | --- |
| 按钮按下仅位移 1px | `:active { transform: scale(0.97) }` | 按压缩放给即时反馈 |
| 触屏 hover 触发位移 | `@media (hover: none), (pointer: coarse)` 关闭 | 触屏 hover 是假状态 |
| 卡片无层次 | 毛玻璃 + 内高光 + 指针倾斜 + 流光 | 卡片是主要收藏物，需要“可触摸”的质感 |
| 切换主战无反馈 | slot-pop / 成员 glow / 筛选淡入 | 让状态变化被看见 |
| 所有动效默认播放 | reduced-motion 关闭位移/抖动/浮字 | 保留内容，去掉运动 |
| 玩家不知道下一步 | 常驻 NextStepBar + 六章指引 + 事件锁解释 | 降低首次游玩卡住概率 |
| 关键数值无解释 | 共鸣/羁绊等 title 提示、战斗 coach line | 术语可发现 |
