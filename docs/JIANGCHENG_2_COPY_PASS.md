# 2.0 游戏内文案润色记录（humanizer-zh）

> 范围：游戏内面向玩家的短文案（事件、区域、指引、结算、任务、进化、Toast）。
> 未改：数值、机制、版本号、内部字段名、测试与文档正文；没有为了“更好看”补写事实或数值。

## 1. 先修事实不一致

这次通读发现 3 处「说明文字和实际效果不一致」，先按代码改文案，而不是按文案改数值：

| 位置 | 原文案 | 实际效果 | 处理 |
|---|---|---|---|
| `ev_zao_second` 坐下来吃完 | 开局护盾 +8，羁绊 +1 | 只加护盾 +8 | 改为「下一场开局 +8 护盾」 |
| `ev_zao_spice` 收下辣油 | Boss 血量 -8%，开局 +6 护盾 | 只削 Boss 血量 | 改为「Boss 血量 -8%」 |
| `ev_sakura_seed` 种在坡上 | 羁绊 +2，开局 +6 护盾 | 只加护盾 +6 | 改为「下一场开局 +6 护盾」 |

另有两处「文本描述和按钮不一致」：

- 桥影工坊「工具箱」：原文说箱子在桥洞，按钮却叫“帮桥工把桥修好”。改为「把工具箱送回去」，仍保留“修桥”留下的线索。
- 雷鸣创想站「主脑的图纸」：原文说“掐掉一个节点”，按钮是“标记节点”。改为“记下其中一个，就够让它分神”。

## 2. 去掉内部术语与错指引

- 指引里的 `flags` 改为 **「线索」**；不向玩家暴露内部字段名。
- 指引曾写“带灯/桥/花/电相关标签的物品会触发隐藏选项”，实际是**前面事件留下的线索**决定是否解锁。已改正，避免玩家带错物品找隐藏选项。
- 事件锁的提示从“不是 bug”改为“这是设计，不是卡住”，保留原意，语气更像游戏内说明。
- 被锁选项的鼠标提示不再显示 `lamp_lit` 这类内部键，改为「需要先留下『把灯点亮』」。
- Boss 阶段说明从“半血/2/3 血”改为“不同 Boss 会在半血或 2/3、1/3 血量时进阶段”，不再把所有 Boss 说成同一套。

## 3. 让句子更像这个世界的人在说话

| 位置 | 原 | 改 |
|---|---|---|
| 过早巷区域副标题 | 锅气、队伍与一碗热干面的火候 | 锅气、人声与一碗热干面的火候 |
| 早味大厨·第二碗 | 汤面很烫 | 面很烫（热干面没有汤） |
| 早市排队 | 摊主看着他，他身后的人都看着摊主 | 摊主看着他，他身后的人看着摊主（去掉重复的“都”和“他”） |
| 结算胜利 | 风暴停了一小会儿 | 这一局，站稳了。 |
| 结算失败 | 这次被潮水压过去了 | 这次被压过去了。 |
| 结算平局 | 打平了，但潮水还没退 | 打平了，谁都没退。 |
| 江风渡口规则 | 有护盾/防御时伤害减半 | 主战有护盾或防御时，范围伤害会被挡下大半 |
| 掌握一条路 | 完成进化并把等级带到 5 | 完成一次进化，再把等级练到 5 |
| 容器系·保温瓶卫 | 把温度和护盾一起拧紧 | 把温度拧紧，也把护盾拧紧 |

结算标题原来把“潮水/风暴”写死在所有区域，换到过早巷、桥影工坊会串味；改成区域无关、只表达胜负的三句。

## 4. 保留没问题的文案

以下没有强行改写：

- 样本提示（“雨天撑开的一小块屋顶”“雾里一声汽笛，江面被划开”）；
- Boss 台词（风雨电台、早味大厨、桥影守卫、樱信档案员、造物夜主脑）；
- 事件正文中已经具体的部分（“每接住一片，就想起一个很久以前的名字”“别把同一招用两次，它都记得”）；
- 机制描述里的数字、限定和条件（护盾 +8、Boss 血量 -8%、3 级、1 信物、8 回合）。
