# 江城万物怪 2.0 · 演示脚本（90 秒 / 3 分钟 / 10 分钟）

> 版本：V1.0（2026-11-19）｜适用：比赛现场、评委巡展、录屏备份
> 重要：本剧本对应 **2.0 目标 UI**（Batch 1/2 实现）。当前仓库只有 P1 的单卡快斗；脚本中出现的「召唤台 / 江城地图 / 队伍工坊」为实施后界面。**演示前必须按 Batch 4 验收实际跑通，不允许用剪辑假装交互。**
> 所有状态都来自真实规则/AI；AI 不可用时用同一条链路的规则模式，并明确说“当前为规则模式”。

## 1. 90 秒版：一把雨伞的逆袭（评委巡展/主舞台）

**目标**：让评委在 90 秒内看到“现实物品语义 → 合法能力 → 真实战斗结果 → 长期进度变化”是同一条链路。

| 时间 | 操作（真实点击） | 屏幕状态 | 说辞（可直接念） | AI 与降级 |
|---|---|---|---|---|
| 0–8s | 捕获站 → 点「雨伞」样本 | 显影；证据标签出现：曲面伞面 / 可折叠 / 遮挡 | “我选一把普通雨伞。模型只负责看和描述，能力由规则编译。” | `analyze_object` 调用（有 Key）；无 Key 用时 8s 内切本地摘要，标签仍出现，字幕“演示模式” |
| 8–18s | 点「遮挡」标签的「我确认」（✓） | 证据徽标变“我确认”；能力预览立即出现「开伞屏障 / 遮挡本能」 | “我确认它真的能遮挡——这一下改变了它的能力，而不是数值。” | 纯规则，0 延迟 |
| 18–28s | 选「守护」倾向 → 点「定形」 | 召唤演出：线稿 → 套印 → 落版；伞面加厚、护盾纹 | “侦察、纠错、选路线，三步它就有了自己的打法。” | 无 AI |
| 28–38s | 点「加入队伍」→ 队伍工坊已含热干面/轮渡 → 点「出发：江风渡口」 | 地图推进到渡口节点 | “三人队：伞负责挡，面条负责缠，轮渡负责换位。” | 无 AI |
| 38–58s | 进入风雨电台 Boss：等它预告「暴雨压境」→ 点雨伞「开伞屏障」 | 暴雨被屏障吸收 → 转为 +2 共鸣；伤害数字显示“挡下” | “Boss 提前预告暴雨。没有伞，全队吃伤害；有伞，暴雨变成资源。” | `battle-director` 可能在 R1 预取；未到则显示“规则意图 · AI 盘算中”，不阻塞 |
| 58–75s | 点轮渡「渡航换位」+ 连携「渡航护盾」 | 双角色交叉换位；护盾图标落下；潮湿清除 | “轮渡把主战拉出危险位；伞的遮挡让换位不挨打。” | AI 只在关键回合；界面显示来源 |
| 75–88s | 击败 Boss → 结算页 | 印章“胜”；掉落潮信信物；图鉴新增；进化预览解锁 | “它救场这一次，会被记进图鉴和后续进化路线。” | 无 AI |
| 88–90s | 切到图鉴/进化预览 | 雨伞两条分支并排 | “下一次打开，我想让它变成疾风型试试——这就是我会再回来的原因。” | — |

**备用台词（模型慢/失败）**：
> “AI 决策这次没在 8 秒内返回，游戏自动用规则出招，界面会标出来——我们不会把规则伪装成 AI。你仍然能看到完整玩法。”

**必须展示的证据**：
1. 证据标签的“看见/推断/我确认”三源。
2. 开伞屏障前后的伤害差（例如 27 → 11）。
3. Boss 预告与玩家应对的因果关系。
4. 结算页的进化/图鉴/信物变化。

## 2. 3 分钟版：两种物品，两套打法

**目标**：证明“不同物品 → 不同机制职责 → 同一挑战不同通关路线”，不是数值比大小。

### 2.1 第一段（0:00–1:20）守护流：雨伞

1. 捕获站选雨伞 → 确认遮挡 → 守护分支 → 定形（复用 90 秒版，语速加快）。
2. 队伍：雨伞 + 水杯（蓄潮）+ 轮渡。
3. 进入江风渡口 · 风雨电台。
4. 打法：R1 蓄潮 → R2 预判暴雨开伞 → R3 渡航换位躲阶段技 → R4 连携渡航护盾 → 磨到 P2 → 用蓄潮爆发收尾。
5. 重点说：“它输出不高，但它让全队少挨两次伤害；这是机制，不是数值。”

### 2.2 第二段（1:20–2:30）控制流：热干面

1. 回城 → 捕获站选热干面 → 确认「细长/缠绕」→ 控制分支 → 定形（可跳过演出）。
2. 队伍：热干面 + 雨伞 + 轮渡（复用角色，换主战顺序）。
3. 同一 Boss，不同打法：热干面用「缠线牵制」打断暴雨预告/回血；雨伞只在收尾保命；轮渡拉位。
4. 重点说：“同一个 Boss，两种完全不同的节奏；热干面不是弱卡，它是另一种解法。”

### 2.3 第三段（2:30–3:00）长期路线

1. 打开进化预览：雨伞两条分支并排（守护伞灵 vs 疾风滑翔者），显示模块差异与外观差异。
2. 打开图鉴：个人造物图鉴 / 区域图鉴 / 能力发现图鉴三层。
3. 结尾：“不同物品引出不同长期路线，这是复玩理由。”

**AI 使用**：两场战斗的关键回合各 1 次 `battle-director`；若延迟，规则兜底不打断。演示时右下角“调用记录”常驻可见（可折叠），随时可自证。

## 3. 10 分钟版：个人江城冒险（完整纵向切片）

**目标**：完整走通“捕获→选择→组队→路线→战斗→成长→进化→图鉴→分享”，全程不读教程。

### 时间表

| 时间 | 场景 | 真实操作 | 观察点/说辞 |
|---|---|---|---|
| 0:00–0:30 | 开场 | 捕获站 → 雨伞样本 | “从一件身边物品开始。” |
| 0:30–1:30 | 捕获/确认/召唤 | 确认“遮挡” → 守护 → 定形 | 强调证据来源与能力预览 |
| 1:30–2:00 | 队伍工坊 | 三人编成；查看连携预览；装备 2 主动 | “搭队伍时就能看到连携条件。” |
| 2:00–3:00 | 江城地图 | 选择江风渡口；查看潮位/节点 | “地图是虚构节点，不是 GPS。” |
| 3:00–4:00 | 节点 1 | 雾航事件：用照明能力点灯 → 隐藏节点 | 事件有机制后果，不是纯文本 |
| 4:00–5:00 | 节点 2 | 普通战：换位 + 防御 + 支援 | 每回合两个有效选择 |
| 5:00–6:30 | 节点 3 | 精英战：控制/护盾/连携 | 失败也能立刻重试，不扣关键资源 |
| 6:30–8:30 | Boss | 风雨电台两阶段；预告→开伞→换位→连携→收尾 | 展示阶段与多解 |
| 8:30–9:00 | 结算/奖励 | 信物、材料、图鉴、下一节点解锁 | “每次探索至少一个新变化。” |
| 9:00–9:30 | 进化 | 雨伞 Lv3 + 印记条件满足 → 两条分支预览 → 选疾风 | 进化改变职责与外观，可回退 |
| 9:30–10:00 | 图鉴/分享 | 锁定卡片；导出角色档案卡；生成挑战码 | 隐私：不含照片/位置；挑战码可复刻 |

**关键验收动作**（演示时确保做到）：
- 打开一次“未发现线索”，显示引导而非问号墙。
- 刷新页面一次（在 9:00 前），确认进度/队伍/图鉴恢复。
- 打开“调用记录”，显示 AI 来源、耗时、模型名。

## 4. 降级矩阵（必须排练）

| 场景 | 现象 | 处理 | 台词 |
|---|---|---|---|
| 无模型 Key | 健康检查 `available=false` | 全流程自动规则；捕获/决策处显示“演示模式” | “现在是没有 Key 的完整演示模式，玩法链路一样，只是 AI 由规则代替。” |
| 模型慢（>8s） | 意图条“规则意图 · AI 盘算中” | 先出招，计划到达后本轮有效；不强等 | “AI 在后台算，游戏不等它。” |
| 模型报错/限流 | fallback 记录 | 规则兜底继续；不重试到卡死 | “本次 AI 调用失败，已回退规则并标注。” |
| 断网 | `/api` 不可达 | 纯演示模式；用预置存档 | “断网也能完整玩规则部分。” |
| 移动端演示 | 375px | 竖直布局；触控目标 ≥44px | 提前用移动端截图备份 |
| 演示存档损坏 | 载入失败 | 用 `?demo=reset` 重置到预置样本；不手改数据 | “我们切到内置样本继续。” |

## 6. 现场问答备稿（30 秒/题）

| 问题 | 回答要点 |
|---|---|
| AI 到底做了什么？ | 四类受限任务：看物体/当敌方指挥官/选事件/推荐进化；全部有 schema 与白名单；不能改数值与胜负；无 Key 时有规则兜底且界面标注。 |
| 和宝可梦像吗？ | 只共享“收集+回合战斗”的通用类型；物品语义编译、江城五区机制、原创视觉与世界都是我们的；不使用任何知名 IP 的名称/造型/地图。 |
| 为什么不会变成“拍照抽卡”？ | 物品不产生稀有度战力；预算恒定，差异来自机制；普通物品也能通关（热干面控制流）。 |
| 深度从哪来？ | 队伍三人、主战/支援、共鸣资源、状态与连携、Boss 阶段与预告；每回合至少两个有效选择。 |
| 10 分钟后玩什么？ | 第二区域、进化分支、区域图鉴、挑战变体、收集补齐；章节报告引用真实游玩记录。 |
| 数据隐私？ | 照片默认不持久化；实时 AI 只上传压缩图并在界面提示；分享卡/挑战码不含照片与位置；Key 只在服务端。 |
| 哪些还没做完？ | 完整 2.0 的五区/主线后半/部分 Boss 与内容在比赛后批次；比赛版两区已闭环，文档里有明确清单与验收。 |
